# AA-5750: Contemporary Issues in Analytics

**From Foundational Machine Learning to Modern AI Systems**

This repository contains course materials for **AA-5750: Contemporary Issues in Analytics** at Saint Louis University (SLU).

The course provides a practical, architecture-driven exploration of contemporary artificial intelligence. Students progress from data augmentation and foundational neural networks to advanced deep learning architectures, transformer-based language models, AI agents, and retrieval-augmented generation (RAG).

Rather than treating AI models as black boxes, the course emphasizes understanding their underlying principles, implementation, architectural design choices, and practical applications through hands-on learning.

## Course Roadmap

The course follows an eight-week progression, connecting foundational machine learning techniques with modern AI systems.

| Week | Topic | Key Concepts |
|---|---|---|
| 1 | Data Augmentation | Data preprocessing, image and text augmentation, dataset diversity, generalization |
| 2 | Multilayer Perceptrons (MLPs) | Neural network fundamentals, forward propagation, backpropagation, activation functions, optimization |
| 3 | Residual Networks (ResNets) | CNN foundations, residual connections, skip connections, deep network training |
| 4 | ResNet: Advanced Exploration | Residual learning, architectural analysis, training experiments, performance evaluation |
| 5 | Sequence Modeling: LSTMs and GRUs | Recurrent neural networks, sequential data, gating mechanisms, long-range dependencies |
| 6 | Transformers and BERT | Attention mechanisms, self-attention, positional encoding, transformer architecture, bidirectional language representations |
| 7 | AI Agents | Agent architectures, tool use, multi-step workflows, reasoning, autonomous task execution |
| 8 | Retrieval-Augmented Generation (RAG) | Embeddings, document retrieval, vector search, retrieval pipelines, grounded generation |

## Weekly Learning Modules

### Week 1 — Data Augmentation

Explore how data augmentation improves the diversity of training data and helps machine learning models generalize beyond their training examples.

Key areas:
- Data foundations and preprocessing
- Text and image augmentation
- Image transformations and augmentation strategies
- Dataset size and diversity
- Evaluating the impact of augmentation on model performance

### Week 2 — Multilayer Perceptrons (MLPs)

Build a foundation in neural network architecture, learning, and optimization.

Key areas:
- Neurons, layers, and network architecture
- Forward propagation and backpropagation
- Activation and loss functions
- Gradient-based optimization
- Model training and evaluation

### Week 3 — Residual Networks (ResNets)

Study the evolution of deep convolutional neural networks and how residual learning addresses optimization challenges in deeper architectures.

Key areas:
- Convolutional neural network foundations
- Residual blocks and skip connections
- Identity mappings and residual learning
- Deep network optimization
- Image classification experiments

### Week 4 — ResNet: Advanced Exploration

Extend the study of ResNets through deeper architectural analysis and practical experimentation.

Key areas:
- Residual network architecture and components
- Training behavior and convergence
- Model configuration and experimentation
- Performance evaluation and error analysis
- Architectural trade-offs

### Week 5 — Sequence Modeling: LSTMs and GRUs

Explore recurrent architectures designed to process sequential data and model temporal dependencies.

Key areas:
- Recurrent neural networks
- Sequential representations and hidden states
- Vanishing and exploding gradients
- Long short-term memory (LSTM) networks
- Gated recurrent units (GRUs)
- Comparing recurrent architectures

### Week 6 — Transformers and BERT

Examine the transition from recurrent sequence modeling to attention-based architectures and modern language representations.

Key areas:
- Attention and self-attention
- Query, key, and value representations
- Positional encoding
- Transformer encoder architecture
- Bidirectional Encoder Representations from Transformers (BERT)
- Pretraining and contextual representations
- Fine-tuning pretrained language models

### Week 7 — AI Agents

Explore AI systems that go beyond single model calls by coordinating reasoning, tools, and multi-step workflows.

Key areas:
- Agent architecture and components
- Tool calling and external integrations
- Planning and task decomposition
- Multi-step execution and feedback
- Agent workflows and orchestration
- Evaluating agent behavior and reliability

### Week 8 — Retrieval-Augmented Generation (RAG)

Study how retrieval systems connect external knowledge to generative language models to support context-aware responses.

Key areas:
- Limitations of standalone language models
- Document processing and chunking
- Text embeddings and semantic search
- Vector retrieval
- Context construction and generation
- Retrieval-augmented generation pipelines
- Evaluating retrieval quality and response grounding

## Learning Approach

The course connects conceptual understanding with practical implementation and empirical evaluation.

Students are encouraged to:

1. **Understand the foundations:** Learn the motivation behind each algorithm and architecture.
2. **Examine the architecture:** Identify the key components and understand how they work together.
3. **Implement and experiment:** Apply concepts through programming exercises and practical demonstrations.
4. **Evaluate performance:** Analyze model behavior, results, and limitations.
5. **Connect ideas across weeks:** Understand how advances in neural networks, sequence modeling, attention, and retrieval contribute to modern AI systems.
